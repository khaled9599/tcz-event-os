# Evidence and Provenance Model

The system distinguishes verified fact, modelled estimate, assumption and inference.

Evidence types include client brief, site measurement, venue document, vendor quote/spec, technical drawing, photo/video, model output, agent inference, human decision, regulation and file artifact.

Verification states: `verified`, `modelled`, `assumed`, `unverified`, `superseded`.

Critical dimensions and capacities do not silently originate from agent inference. Protected mutations must trace to evidence and/or explicit decisions. Derived artifacts record source IDs and versions.
