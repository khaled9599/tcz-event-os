# Visual Critique

Evaluate renders against approved visual targets and measurable design intent.

## Procedure
1. Compare composition, scale, silhouette, material, lighting, branding and venue integration.
2. Separate target mismatch from renderer/artifact defects.
3. Score dimensions against the project rubric.
4. Name the highest-leverage correction first.
5. Stop loops when threshold is met or progress stalls.
6. Never let subjective polish override a canonical dimension or approved brand rule.

## Output
scores, blockers, visual_mismatches, prioritized_revisions, pass_threshold_status.

Adapted from Dream Loop critic-loop concepts and source-locked validation patterns from cc-blender-skill.
