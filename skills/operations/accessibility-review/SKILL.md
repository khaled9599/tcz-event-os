# Accessibility Review

Check event routes and touchpoints for accessible use and flag requirements needing jurisdiction-specific confirmation.

## Procedure
- trace accessible arrival-to-experience route continuity
- review entrances, ramps, circulation widths, seating/viewing, counters, signage and restroom access
- check that service/queue design does not create avoidable barriers
- record measured clearances and source evidence
- never claim legal compliance without current authoritative jurisdictional evidence

## Output
accessible_routes, touchpoint_findings, measured_clearances, blockers, evidence_gaps, authority_review_required.
