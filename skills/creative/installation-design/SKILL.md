# Installation Design

## Purpose
Turn approved event concept into a dimensioned installation proposal that can be reviewed for spatial quality and production feasibility.

## Inputs
- canonical installation object
- venue/zone geometry
- creative intent and brand rules
- guest interaction requirements
- verified scale anchors
- budget and schedule constraints

## Procedure
1. Lock the source hierarchy: verified dimensions first, then approved references, then mood references.
2. Define function, guest interaction, silhouette, primary proportions, clear openings, service access, and branding zones.
3. Express geometry parametrically where practical so changes remain traceable.
4. Separate primary structure, secondary frame, substrate, scenic finish, branding, lighting/AV interfaces, anchoring, and service routes.
5. Flag production assumptions instead of solving engineering beyond authority.
6. Create at least one measurable acceptance view or drawing.
7. Handoff to Production Engineering with dimensions, material intent, connection assumptions, unknowns, and evidence.

## Output contract
Return installation proposal, dimension set, assembly layers, material intent, interface requirements, assumptions, unresolved risks, and files/evidence.

## Blockers
- unverified critical venue dimension
- inaccessible guest opening
- design depends on impossible/unknown support condition
- brand lockup altered without approval

## Source synthesis
TCZ adaptation of reference-engineering workflows, Rhino/Grasshopper parametric design patterns, and production assembly thinking from reviewed repositories.
