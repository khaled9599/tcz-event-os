# Show Control

Coordinate show cues across lighting, audio, video, playback, automation and operators.

## Procedure
- derive cue list from approved run of show
- define trigger, time/timecode, systems affected and expected state
- map dependencies and readiness gates
- define fallback behavior for critical cues
- identify rehearsal requirements and operator ownership
- do not change underlying system specs without a change request

## Output
cue_stack, trigger_map, system_dependencies, fallbacks, rehearsal_plan, unresolved_readiness_items.
