# AV System Design

Define LED, projection, audio, playback, processing, networking, signal routing and redundancy as one coordinated system.

## Procedure
- resolve system requirements from show/content/spatial needs
- define devices, dimensions, signal paths and backups
- record content resolution and ownership
- expose power and rigging dependencies explicitly
- validate compatibility across source, processor and display endpoints
- never silently resize approved screens or alter spatial design

## Output
system_diagram, equipment_schedule, signal_flow, redundancy_plan, dependencies, unresolved_vendor_data.
