# Reference Engineering

## Purpose
Build an authoritative reference set before design/modeling work begins.

## Source hierarchy
1. measured/verified project evidence
2. approved client assets and venue documentation
3. authoritative technical references
4. approved visual references
5. mood/inspiration only

## Procedure
- Gather scale anchors, orthographic views, materials, construction cues and brand assets.
- Label every source by authority and intended use.
- Do not use mood imagery as dimensional evidence.
- Audit for missing angles, scale, material and connection information.
- Package only task-relevant references for downstream agents.

## Output
reference_manifest, authority_labels, missing_reference_gaps, approved_usage.
